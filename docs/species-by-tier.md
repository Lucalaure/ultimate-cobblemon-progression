# Species by Tier and Rarity

> Generated by `scripts/generate-species-reference.ps1` from UCP's default tier files and the natural spawn data of Cobblemon 1.8. Do not edit by hand - re-run the script instead.

This page answers two separate questions for every Pokémon that spawns naturally in base Cobblemon:

- **Tier** (from this mod): the trainer level you need before it can spawn for you at all.
- **Rarity** (from Cobblemon): which spawn bucket it lives in, which controls how often it appears once it is allowed.

See [How UCP Works](how-it-works.md) for how the two combine. Rarity odds per spawn attempt (Cobblemon defaults):

| Rarity | World spawns | Fishing / PokeSnack |
|---|---|---|
| Common | 94% | 83.25% |
| Uncommon | 5% | 11.25% |
| Rare | 0.5% | 4.125% |
| Ultra-rare | 0.2% | 1.375% |
| Boss | 0.3% | - |

A Pokémon can appear under more than one rarity (for example, its regional form may be rarer than its regular form). Forms are listed separately when their rarity differs, but **a form always shares its species' tier**.

## Tier entries that don't match a Cobblemon species

The tier files also list Pokémon from add-ons (Myths and Legends, Mega Showdown, MysticMons, and others) and some regional forms written as separate ids (like `bergmite_hisui`). Cobblemon treats regional forms as forms of the base species, so those form entries have no effect: the form uses its base species' tier. Add-on entries only take effect when that add-on is installed.
